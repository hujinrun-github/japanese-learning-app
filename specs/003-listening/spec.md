# 听力训练（一期）

## 目标与范围

在现有教材音频、逐句字幕、词汇复习和学习计划之上，建立「盲听理解 → 定位漏听点 → 逐句精听 → 关闭文本复测 → 到期复习」的训练流程。以 N2 教材理解为首批内容，同时支持按 N5–N1 筛选；没有材料的等级显示真实空状态。

一期提供教材精听、理解选择题、听不清句子标记、训练断点、独立听力进度、到期复习及每日听力任务联动。听写、录音评分仍属于已有相应模块，不作为听力掌握的证据。JLPT 全真模拟、新闻泛听、实时自动出题及新的录音评分不在一期范围。

## 入口与素材库

- 桌面导航、移动端底部导航的可达菜单及首页提供「🎧 听力」入口，指向 `/listening`；训练详情为 `/listening/{正整数教材ID}`。
- 列表支持等级以及全部、未练习、已练习、待复习状态，显示标题、音频时长、题数和继续训练入口。
- 正式训练需有可播放音频、有效且按顺序对应文本的句子时间轴、至少一道已发布理解题。缺少音频、时间轴或题目时如实提示，不能把不可用材料当作可测评内容。
- 空列表、加载失败、音频失败、重新读取和返回素材库均须有明确可见的操作文字。

## 训练流程

1. **盲听**：默认隐藏日文、中文和假名，不提供原文显示入口；允许播放、暂停、重听后回答理解选择题。提交前服务端不下发正确答案、解析或证据句索引。盲听和复测中如通过播放器控制使用慢放，记录为有辅助。
2. **精听**：盲听提交后，显示答题结果、中文解释和对应证据句。支持选择任一句播放、循环、变速、文本和中文显隐，保存「听不清」句子。日文/中文显隐不应改变用户已提交的首次成绩。
3. **复测**：完成精听后关闭文本，重新听音并作答。复测成绩与首次盲听成绩分开保存；同题复测只表示本次练习中的纠错情况，不等同于未见材料的能力测试。
4. **完成**：只有已提交本轮盲听与复测后才能完成训练。服务端检查阶段顺序，不接受前端直接跳过阶段打卡；完成后保存复习到期时间。
5. **复习**：到期材料优先进入新一轮训练，已完成轮次与历史成绩保留。复习周期按简单规则递进；界面说明复练有记忆影响，不给出未经校准的 JLPT 预测分。

浏览器刷新或离开页面后，恢复本轮阶段、播放位置、当前句、听不清标记和未提交答案。更换材料不得沿用上一材料答案。重复点击、网络重试及相同幂等键不能重复生成尝试记录；同键内容不同须拒绝。所有记录按登录用户隔离。

顶部步骤可进入已开放的阶段。回看此前步骤时保留本轮已保存的阶段、答题草稿和播放断点。复测提交后可先查看本轮成绩，确认完成时安排复习并触发当日听力打卡。完成一轮后可回看所有步骤，使用「再练一轮」开启新的训练记录。

完成后的「下一篇未练习」沿用进入训练时的等级范围，按素材库顺序跳过已练习及无法完成训练的素材。到达末尾时可继续前面尚未练习的素材。没有可用下一篇时停在训练结果，可手动返回原筛选范围的听力库。

## 内容与发布

- 新增 PostgreSQL `018_listening.sql`，独立保存理解题、听力进度和听力尝试；复用现有 `lessons` / `lesson_sentences`，不复制教材或新增独立音频存储。
- `019_listening_content.sql`包含已阅读原文后编写的20篇N2教材、40道理解题；每题四个选项、唯一正确答案、中文解析和一个证据句索引。选材为「日语阅读素材001–020」。它们是教材理解训练题，不标记为 JLPT 真题。
- `024_listening_my_day.sql` 为 N5《私の一日》补充 3 道理解题，并复用原音频和时间轴。已经从精听开始的学习者可补做本轮首次理解题，再进入复测。
- 每篇内容按教材标题、等级和**完整有序日文句子数组**精确匹配。教材缺失、正文被修改或句子位置不符时不插入题目；不硬编码生产教材ID、不修改原文、不覆盖已有问题。
- `go run ./backend/cmd/appctl seed-listening`（或 `make seed-listening`）通过现有 PostgreSQL 数据访问层重复执行同一受版本控制的补题语句。空库先迁移、后导入教材的场景仍可补题；重复执行不产生重复问题。
- 音频标明合成音/真人来源；首批材料复用已有音频，不重新生成。公开教材外链不自动转为站内复制内容。新内容发布前检查音文一致、句子时段有效、选项唯一和解释依据。

## 学习计划兼容

- 新N2模板每日20分钟听力目标为 `/listening?level=N2`，保持既有三个时段、星期、日期、时区、其余目标和周末休息安排。
- 旧保存计划中**只有**`task.id=listening`且目标恰为 `https://www.jlpt.jp/e/samples/sampleindex.html` 时，读取今日任务/展示入口时解析为站内N2听力。非听力的官方周测外链、自定义目标及保存的计划JSON均不自动重写。
- 安全入口白名单增加 `/listening` 和 `/listening/{正整数ID}`，拒绝协议相对地址、路径穿越、零ID、负ID及多余路径段。
- 完成一次完整训练时，由听力完成事务调用 `studyplan.CompleteListeningTask`，只标记用户保存计划时区的**当天**首个内置听力任务。休息日、计划开始前/结束后、无计划、未安排听力或把听力任务改为别的模块时不生成完成记录。
- 自动完成幂等；手动勾选/撤销继续可用。听力训练完成、理解成绩与每日打卡是三个不同概念，不从播放次数或口语得分推导掌握程度。

## 验收

- 可在桌面和移动端找到听力入口；从今日N2听力任务进入站内素材库。
- 完成一篇真实教材的盲听、精听、复测并刷新，结果与阶段保持；首次盲听和复测分别可见。
- 服务端拒绝越阶段提交、无效题目或选项、跨用户记录和冲突的幂等请求；网络重试不重复计数。
- 首批20篇素材与缓存音频逐句一致，40题均有有效证据句；精确匹配补题、重复补题及正文修改后拒绝错配通过真实PostgreSQL测试。
- 自动打卡按计划时区与日期隔离；午夜、休息日、无计划、旧官方入口及自定义入口均有测试。
- 集成测试通过 `internal/testdb` 在独立测试库的临时schema运行，不清理或写入线上业务schema。
