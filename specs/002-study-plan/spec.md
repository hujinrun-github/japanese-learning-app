# 用户学习计划与 Apple 日历

- 每个已登录用户保存一份学习计划，可创建、修改、删除。
- 配置标题、开始/结束日期（一年内）、学习日、每日当地时间、IANA 时区、学习时长、提前提醒、单词及语法目标。
- 计划按用户隔离，唯一数据库为 PostgreSQL；集成测试使用独立测试库中的临时 schema。
- 为用户生成独立随机只读日历订阅地址（不使用登录 JWT），提供 webcal 订阅与 .ics 下载，支持重置链接。
- 日历生成 VEVENT 与 DISPLAY VALARM，保持同一用户同一日期 UID 稳定，按本地日期生成以兼容夏令时。
- Apple 日历首次订阅需用户确认并开启事件提醒；后续由客户端定期刷新。下载导入为一次性快照。
- 删除计划使订阅地址失效；设备残留日程需取消订阅。重置后需重新订阅。
- 这里的提醒为日历事件提醒，并非 Apple「提醒事项」App 独立任务。
- 桌面导航及移动更多菜单均提供入口，账号菜单提供首页入口。

## 工作日多时段学习计划（2026-11-19）

- 一份计划可配置最多三个时段，每个时段包含稳定 ID、名称、开始时间、分钟数和任务列表；已有单时段计划继续读取、编辑和订阅。
- 任务包含稳定 ID、标题、学习说明、分钟数、学习入口及可选适用星期。未指定星期时继承计划学习日；任务可按周一、周二至周四、周五分别安排。计划学习日是总开关，任务可保留暂未启用日期的定义；取消再恢复某个学习日不得丢失原任务。
- 同一天的时段不能重叠或跨午夜；任务时长为正数，同一时段当日任务总时长不得超过时段长度。日期、时区、星期、ID 和学习入口在服务端校验。
- 提供 N2 工作日模板：周一至周五，Asia/Shanghai；午间 12:50–13:10 词汇，傍晚 18:40–19:00 听力，晚间 22:00–23:00 学习。周末完全不安排任务。可编辑时段后保存，不能在页面加载时覆盖用户原计划。
- 周一晚间：20 分钟补漏洞、30 分钟阅读、10 分钟错题；周二至周四：20 分钟语法、30 分钟阅读、10 分钟错题；周五：45 分钟限时分项测验、15 分钟分析。午间周一与周五以旧词复习为主，其余工作日先复习再学少量新词。
- 听力任务先盲听答题，再对照文本重听；官方 N2 练习材料作为有明确标签的外链。项目内词汇、语法、阅读入口应保留 N2 等级。
- 学习计划页和首页显示按计划时区解析的当天三个时段与具体任务；非学习日、计划开始前和结束后显示相应空状态，不生成任务。首页有多时段计划时不再显示相冲突的默认每日任务卡。
- 当天任务可手动完成或取消，完成状态按用户、当地日期、时段和任务隔离，刷新后恢复；这不是模块自动完成计数。只允许修改当天实际安排的任务，跨午夜的过期提交应拒绝。
- 日历为每个时段生成独立事件，说明包含当天适用任务；不同日期或时段 UID 唯一，同一时段调整时间后 UID 保持稳定，旧单时段 UID 保持兼容。
- API 新增 `GET /api/v1/study-plan/today` 和 `PUT /api/v1/study-plan/tasks/{slotID}/{taskID}`。计划 JSON 新增可选 `time_slots`，完成记录通过新增 PostgreSQL 迁移保存，不修改已发布迁移。
