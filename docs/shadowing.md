# 日语跟读 Web App 学习页设计方案

## 1. 功能定位

本页面是日语跟读 Web App 的核心学习页面，主要用于用户观看日语视频、同步查看字幕、逐句跟读、录音练习和复习当前句子。

页面的核心目标是让用户在学习过程中始终清楚：

```text
1. 当前视频播放到哪一句
2. 当前需要练习哪一句
3. 当前句的日文、假名和中文含义
4. 可以对当前句进行重播、慢速播放、录音跟读和回放
```

该页面不是普通视频播放页，而是围绕“当前句”进行训练的跟读学习页。

---

## 2. 核心使用流程

用户进入页面后的主要学习路径为：

```text
进入课程学习页
↓
播放视频
↓
视频时间与字幕自动同步
↓
当前字幕自动高亮并滚动到可视区域
↓
当前句显示在跟读卡片中
↓
用户可选择重播、慢速播放、循环本句或录音跟读
↓
完成当前句练习后进入下一句
```

跟读训练闭环为：

```text
听原音 → 看字幕 → 重播 → 慢速听 → 录音跟读 → 播放自己的录音 → 查看评分 → 下一句
```

## 4. 页面模块说明

### 4.1 顶部栏

顶部栏用于展示课程信息和全局设置，不承载高频跟读操作。

建议内容：

```text
← 课程库    第 3 课：コンビニで買い物    完成度 32%    字幕设置    继续学习
```

模块说明：

| 模块   | 说明           |
| ---- | ------------ |
| 返回按钮 | 返回课程列表或课程详情页 |
| 课程标题 | 显示当前学习课程名称   |
| 学习进度 | 显示当前课程完成度    |
| 字幕设置 | 打开字幕设置面板     |
| 继续学习 | 从上次学习位置继续播放  |

顶部栏设计建议：

```text
高度：56px
背景：白色
底部边框：1px 浅灰
标题字号：16px - 18px
操作按钮字号：14px
```

---

### 4.2 视频播放区

视频播放区位于页面上方，是用户听原音和观看画面的核心区域。

视频区内容包括：

```text
1. 视频画面
2. 当前日文字幕 Overlay
3. 播放 / 暂停
4. 当前时间 / 总时长
5. 播放进度条
6. 倍速切换
7. 全屏按钮
```

视频区域示意：

```text
┌────────────────────────────────────────┐
│                                        │
│                视频画面                 │
│                                        │
│                                        │
│ 当前句字幕：                            │
│ すみません、このお弁当はいくらですか。  │
│                                        │
│ ▶ 01:24 ━━━━━━━━━──── 08:30   1.0x     │
└────────────────────────────────────────┘
```

视频区交互：

| 操作      | 行为               |
| ------- | ---------------- |
| 播放      | 视频开始播放，字幕开始同步    |
| 暂停      | 视频暂停，字幕保持当前句     |
| 拖动进度条   | 视频跳转到指定时间，字幕同步跳转 |
| 倍速切换    | 改变视频播放速度         |
| 全屏      | 视频进入全屏播放         |
| 点击当前句重播 | 视频跳回当前句开始时间      |

倍速建议：

```text
0.75x：慢速听清
1.0x：正常播放
1.25x：提高训练
```

---

### 4.3 当前句跟读卡

当前句跟读卡是本页面最重要的学习区域，用来展示当前正在练习的句子，并提供跟读操作。

设计目标：

```text
1. 当前句永远清楚可见
2. 高频操作离当前句足够近
3. 用户不用在字幕列表里找当前句
4. 用户可以围绕一句话反复训练
```

当前句跟读卡示意：

```text
┌────────────────────────────────────┐
│ 当前句跟读                           │
│                                    │
│ すみません、このお弁当はいくらですか。 │
│                                    │
│ すみません、この おべんとうは         │
│ いくらですか。                       │
│                                    │
│ 不好意思，这个便当多少钱？            │
│                                    │
│ [🎙 跟读] [重播]                     │
│ [慢速 0.75x] [循环本句]              │
│ [播放录音] [收藏]                    │
│                                    │
│ 上次评分：86                         │
│ 发音提示：注意「お弁当」的重音         │
└────────────────────────────────────┘
```

展示字段优先级：

| 层级 | 内容    | 说明          |
| -- | ----- | ----------- |
| 一级 | 日文原文  | 字号最大、最醒目    |
| 二级 | 假名    | 用于辅助读音      |
| 三级 | 中文翻译  | 帮助理解含义      |
| 四级 | 操作按钮  | 跟读、重播、慢速、循环 |
| 五级 | 评分与提示 | 展示上次练习结果    |

按钮优先级：

| 按钮   | 优先级 | 说明               |
| ---- | --: | ---------------- |
| 跟读   |  最高 | 主操作按钮，建议使用红色或醒目色 |
| 重播   |   高 | 高频训练动作           |
| 慢速播放 |   高 | 初学者常用            |
| 循环本句 |   中 | 用于精听和纠音          |
| 播放录音 |   中 | 录音后出现或可用         |
| 查看评分 |   中 | 查看 AI 评分或发音分析    |
| 收藏句子 |   低 | 用于复习和错句本         |

### 4.4 字幕时间轴

字幕时间轴用于展示完整字幕上下文，并随着视频播放自动同步。

字幕时间轴不是普通文本列表，而是一个可点击、可同步、可滚动的时间轴。

字幕区示意：

```text
┌──────────────────────────────────────────────┐
│ 字幕时间轴                         自动跟随  │
├──────────────────────────────────────────────┤
│ 店員：いらっしゃいませ。                     │
│ てんいん：いらっしゃいませ。                 │
│ 店员：欢迎光临。                             │
│                                              │
│ ▌ すみません、このお弁当はいくらですか。     │
│   すみません、この おべんとうは いくらですか。│
│   不好意思，这个便当多少钱？                 │
│                                              │
│ それは五百円です。                           │
│ それは ごひゃくえんです。                    │
│ 那个是五百日元。                             │
└──────────────────────────────────────────────┘
```

字幕行内容：

```text
日文原文
假名
中文翻译
```

当前字幕高亮规则：

```text
背景：浅蓝色
左侧：蓝色竖线
日文：加粗，字号变大
假名：蓝色或辅助色
中文：灰色
```

字幕列表交互：

| 操作     | 行为             |
| ------ | -------------- |
| 视频播放   | 当前字幕自动高亮       |
| 当前时间变化 | 字幕列表自动滚动到当前句   |
| 点击某句字幕 | 视频跳转到该句开始时间    |
| 手动滚动字幕 | 暂停自动跟随几秒       |
| 开启自动跟随 | 当前句始终滚动到可视区域中间 |

字幕区设置项：

```text
显示 / 隐藏假名
显示 / 隐藏中文
字体大小调整
自动跟随开关
只看日文模式
中日双语模式
```

## 5. 关键交互流程

### 5.1 视频播放时的字幕同步流程

```text
视频开始播放
↓
前端实时获取 video.currentTime
↓
根据 currentTime 匹配字幕 start / end 时间
↓
找到当前字幕 index
↓
更新当前句跟读卡
↓
高亮字幕时间轴中的当前句
↓
字幕列表自动滚动，让当前句居中显示
```

核心逻辑：

```text
currentTime >= subtitle.start
并且
currentTime <= subtitle.end

则该 subtitle 为当前字幕
```

---

### 5.2 点击字幕跳转流程

```text
用户点击某一句字幕
↓
获取该字幕的 start 时间
↓
设置 video.currentTime = subtitle.start
↓
视频跳转到该句
↓
当前句跟读卡更新
↓
字幕列表高亮该句
↓
视频开始播放
```

建议点击字幕后默认开始播放，这样学习体验更连贯。

---

### 5.3 重播当前句流程

```text
用户点击“重播”
↓
视频跳转到当前句 start 时间
↓
播放当前句
↓
播放到当前句 end 时间
↓
根据当前练习模式决定是否暂停
```

在“听一句停一句”模式下，播放完当前句后自动暂停。

在“普通播放”模式下，播放完当前句后继续播放下一句。

---

### 5.4 慢速播放流程

```text
用户点击“慢速播放”
↓
设置 video.playbackRate = 0.75
↓
视频跳转到当前句 start 时间
↓
播放当前句
```

慢速播放适合用户听不清或需要模仿语音语调时使用。

---

### 5.5 循环本句流程

```text
用户点击“循环本句”
↓
视频跳转到当前句 start 时间
↓
开始播放
↓
当 currentTime >= 当前句 end 时间
↓
再次跳回当前句 start 时间
↓
持续循环，直到用户关闭循环
```

循环本句适用于精听、纠音、语调模仿训练。

---

### 5.6 录音跟读流程

```text
用户点击“跟读”
↓
暂停视频
↓
开始录音
↓
按钮状态变为“停止录音”
↓
用户再次点击，结束录音
↓
显示“播放录音”和“查看评分”
↓
用户可以播放自己的录音进行对比
```

后续可接入 AI 发音评分，显示：

```text
总评分
发音准确度
流利度
重音提示
错误音节提示
```

## 6. 跟读模式设计

页面建议提供三种练习模式。

| 模式     | 适用场景    | 行为             |
| ------ | ------- | -------------- |
| 普通播放   | 泛听、预览课程 | 视频连续播放，字幕自动滚动  |
| 听一句停一句 | 初学者跟读   | 每句播放结束后自动暂停    |
| 循环本句   | 精听、纠音   | 当前句反复播放，直到用户关闭 |

默认模式建议：

```text
新用户：听一句停一句
熟练用户：普通播放
精听用户：循环本句
```

模式切换可以放在当前句跟读卡中，也可以放在字幕设置面板中。

## 7. 移动端设计优化

移动端不使用左右分栏，而是采用单列结构。

移动端布局：

```text
顶部栏
↓
视频播放区
↓
当前句跟读卡
↓
字幕时间轴
↓
底部固定练习栏
```

移动端页面示意：

```text
┌────────────────────────────┐
│ コンビニで買い物      32%  │
├────────────────────────────┤
│                            │
│          视频播放区         │
│                            │
├────────────────────────────┤
│ 当前句                      │
│ すみません、このお弁当は...  │
│ すみません、この おべんとう...│
│ 不好意思，这个便当多少钱？   │
│                            │
│ [跟读] [重播] [慢速]        │
├────────────────────────────┤
│ 字幕时间轴                  │
│                            │
│ 店員：いらっしゃいませ。     │
│                            │
│ ▌ すみません、このお弁当は...│
│                            │
│ それは五百円です。           │
├────────────────────────────┤
│ 上一句     重播   录音   下一句 │
└────────────────────────────┘
```

移动端底部固定栏：

```text
[上一句] [重播] [录音] [下一句]
```

底部固定栏设计原因：

```text
1. 手机端用户常用操作集中在底部
2. 方便单手操作
3. 不需要滚动页面也能重播和录音
4. 更适合碎片化学习
```

## 9. 页面状态设计

### 9.1 普通状态

```text
视频正常播放
字幕自动同步
当前句高亮
当前句卡片显示当前内容
```

---

### 9.2 暂停状态

```text
视频暂停
当前句保持高亮
用户可以重播、录音、点击字幕跳转
```

---

### 9.3 录音状态

```text
视频暂停
录音按钮变为“停止录音”
显示录音中状态
可展示录音波形或计时
```

示意：

```text
正在录音 00:06
● ● ● ● ● ● ●
[停止录音]
```

---

### 9.4 评分完成状态

```text
显示本次跟读评分
显示发音提示
显示“播放录音”和“再读一次”
```

示意：

```text
本次评分：86
发音准确度：良好
提示：注意「お弁当」的重音
[播放录音] [再读一次]
```

---

### 9.5 自动跟随关闭状态

当用户手动滚动字幕时，系统可以短暂停止自动跟随。

```text
用户手动滚动字幕
↓
自动跟随暂停 3 秒
↓
页面提示：已暂停自动跟随
↓
3 秒后恢复自动跟随
```

也可以提供手动开关：

```text
自动跟随：开 / 关
```

## 12. 字幕同步核心逻辑

根据视频当前播放时间匹配字幕：

```ts
function findSubtitleIndex(time: number, subtitles: SubtitleItem[]) {
  return subtitles.findIndex(
    item => time >= item.start && time <= item.end
  );
}
```

字幕数量较多时，推荐使用二分查找：

```ts
function findSubtitleIndexByTime(time: number, subtitles: SubtitleItem[]) {
  let left = 0;
  let right = subtitles.length - 1;

  while (left <= right) {
    const mid = Math.floor((left + right) / 2);
    const item = subtitles[mid];

    if (time < item.start) {
      right = mid - 1;
    } else if (time > item.end) {
      left = mid + 1;
    } else {
      return mid;
    }
  }

  return -1;
}
```

视频播放时同步字幕：

```ts
video.addEventListener("timeupdate", () => {
  const index = findSubtitleIndexByTime(video.currentTime, subtitles);

  if (index !== -1 && index !== activeSubtitleIndex) {
    setActiveSubtitleIndex(index);
    scrollSubtitleIntoView(index);
    updateCurrentSentenceCard(index);
  }
});
```

## 13. 自动滚动逻辑

当前字幕变化时，让字幕滚动到可视区域中间。

```ts
function scrollSubtitleIntoView(index: number) {
  const element = subtitleRefs.current[index];

  if (!element) return;

  element.scrollIntoView({
    behavior: "smooth",
    block: "center"
  });
}
```

需要注意用户手动滚动冲突：

```text
1. 用户手动滚动字幕区
2. 暂停自动跟随 3 秒
3. 3 秒内不自动 scrollIntoView
4. 3 秒后恢复自动跟随
```

## 14. 页面优化重点

### 14.1 增加当前句跟读卡

优化前：

```text
用户只能在字幕列表中找当前句
```

优化后：

```text
当前句独立展示，用户始终知道自己正在练哪一句
```

---

### 14.2 高频操作靠近当前句

优化前：

```text
重播、录音、慢速按钮分散
```

优化后：

```text
重播、慢速、录音、循环都围绕当前句出现
```

---

### 14.3 字幕列表只负责定位和上下文

字幕列表不要承担所有操作，避免页面复杂。

字幕列表主要负责：

```text
1. 展示上下文
2. 当前句高亮
3. 点击跳转
4. 自动滚动
```

---

### 14.4 视频区保留简短字幕 Overlay

视频画面上只显示当前日文句子，不显示假名和中文。

原因：

```text
1. 不遮挡视频内容
2. 减少视觉负担
3. 用户可以快速确认当前播放内容
```

完整信息放在当前句跟读卡和字幕时间轴中。

---

### 14.5 移动端增加底部固定练习栏

移动端高频操作包括：

```text
上一句
重播
录音
下一句
```

这些操作应固定在屏幕底部，便于单手使用。

## 17. 最终设计原则

本页面的设计原则可以总结为：

```text
一句话一个练习任务
当前句永远可见
重播和录音永远在手边
视频负责听和看
字幕列表负责同步和定位
当前句卡片负责练习动作
移动端优先保证单手操作
```

这套设计既能满足“视频播放到哪里，字幕移动到哪里”的基础需求，也能支持日语跟读软件后续扩展录音、评分、纠音、生词收藏和学习记录等能力。
